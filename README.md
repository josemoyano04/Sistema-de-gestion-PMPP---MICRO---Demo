# Sistema de Gestión de Pañol y Setups (PMPP) — MICRO Automación (Demo)

Demo navegable e interactiva desarrollada en Vanilla HTML, CSS y JavaScript (SPA modular sin frameworks) para el Sistema de Gestión de Pañol de Mecanizado y Puesta a Punto de Máquinas de MICRO Automación.

## 🚀 GitHub Pages
Accede a la demo en vivo: [https://josemoyano04.github.io/Sistema-de-gestion-PMPP---MICRO---Demo/](https://josemoyano04.github.io/Sistema-de-gestion-PMPP---MICRO---Demo/)

## 📂 Estructura del Proyecto
- `index.html`: Entry point configurado para GitHub Pages (redirecciona o sirve `app/index.html`).
- `app/`: Aplicación principal (HTML, CSS modular, Vanilla JS y assets).
  - `index.html`: Shell SPA de la aplicación.
  - `css/`: Estilos modulares (`base.css`, `layout.css`, `components.css`).
  - `js/`: Lógica dividida por módulos (`router.js`, `data.js`, `utils.js`, `dashboard.js`, `stock.js`, `accesorios.js`, `setups.js`, `fichas.js`).
  - `assets/`: Logo y recursos gráficos.
- `spec/`: Especificación técnica y requerimientos del proyecto.
